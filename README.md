# DNH W3 🐦

A colorful 2D flying game by **ALID Studio**. Choose your bird, dodge the obstacles, and try to beat your best score!

## 🎮 Play the Game

[Play DNH W3 in your browser on itch.io](https://alid-studio.itch.io/dnh-w3)

## ✨ Features

- 🐤 Choose from three playable birds
- 🌄 Fly through a colorful scrolling world
- 🪵 Dodge obstacles and avoid the ground
- ⏱️ Start each run with a countdown
- 🏆 Earn points and track your best score
- 💾 Best score is saved in your browser
- 🔊 Turn the music on or off
- 🔁 Restart a run or return to the main menu

## 🕹️ Controls

- **G** — Start the countdown
- **Space** or **left mouse button** — Flap upward

## 🛠️ Built With

- **Unity**
- **C#**
- **Unity Input System**
- **TextMeshPro**
- **WebGL**
